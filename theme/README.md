# Light + Form (Dethok) Shopify theme

Online Store 2.0 port of the static Light + Form Concepts site (CSS/markup class names match the static pages). Based on Shopify Skeleton (MIT, see LICENSE.md).

- Lint: `shopify theme check`
- Push to the build theme (never the live one): `shopify theme push --theme <ID> --store 26gcsf-0y.myshopify.com`
- Checks: `~/.venvs/automation/bin/python scripts/check_theme.py --theme <ID>` (run from repo root)

Theme id on store: 168112324747
